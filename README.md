# Introduction

This repository contains all the ARM templates for the digital forms  project.

## Getting Started

To use this repo, you will need to have a working copy of Visual Studio Code with the following extensions:

* Azure Pipelines
* Azure Resource Manager (ARM) Tools

## Working with this repo

To work on this repository,  create a feature branch, perform whatever work is required and create a pull request into the main branch,  associating the pull request with a work item.

The easist way of doing this is as part of the message in the first commit, using the following as a template:

```text
<brief description> (#<work item>)

<details>
```
